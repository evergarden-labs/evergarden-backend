# evergarden-backend

**에버가든**은 여행 기록을 재사용 가능한 코스 데이터로 바꾸는 아카이빙 플랫폼이다.

사진은 갤러리에, 동선은 지도 앱에, 감상은 일기장에 흩어져 여행의 서사가 휘발된다.
에버가든은 이를 한곳에 모으고, **남이 그대로 가져다 쓸 수 있는 코스**로 구조화한다.
개인의 주관적 기록에 한국관광 콘텐츠랩의 공신력 있는 관광 데이터를 붙여 정보의 빈틈을 메운다.

---

## 무엇을 할 수 있나

### 여행을 계획한다 — 플래너

여행지(복수)와 기간을 정해 일정을 만들고, 장소를 검색해 일자별로 배치한다.
장소 정보는 콘텐츠랩에서 가져와 이름·좌표·이미지·운영 시간까지 채운다.

- **주변 추천** — 그 날 담긴 장소들 반경 5km에서 찾아준다. 이미 담은 곳은 뺀다
- **자동 배치** — 이동 거리가 짧아지는 순서를 계산해 **제안**한다. 적용은 사용자가 고른다
- **코스 시각화** — 일자별 동선과 이동 반경을 지도에 그린다

### 다녀온 곳을 남긴다 — 아카이브

폴라로이드·스크랩북 같은 테마를 골라 사진과 영상을 캔버스에 배치한다.
사진마다 캡션을 달 수 있고, 여행 기간은 **사진의 촬영 시각에서 서버가 계산**한다.

- **공동 편집** — 동행자를 닉네임으로 초대해 함께 꾸민다. 변경이 실시간으로 반영된다
- **복제** — 함께 만든 앨범을 내 기록으로 가져간다

### 다녀온 지역이 정원이 된다 — 지도 · 정원

그 지역에서 위치 인증을 하면 지도에 색이 칠해지고 전용 식물이 해금된다.
다시 가면 자란다. 다만 같은 지역은 **7일에 한 번만** 성장에 반영된다.

### 미래의 나에게 남긴다 — 타임캡슐

사진과 글을 봉인하고 **날짜 또는 장소**를 해제 조건으로 건다.
조건이 충족되기 전에는 본인도 내용을 볼 수 없다.

### 나누고 가져간다 — 커뮤니티

완성한 코스와 아카이브를 게시물로 공유한다. 둘 다 올릴 수도, 하나만 올릴 수도 있다.

- 게시물은 **코스에 담긴 모든 지역의 피드**에 노출된다
- 남의 코스를 **내 일정으로 복사**해 날짜만 바꿔 떠날 수 있다
- 아카이브는 **틀만** 가져온다. 사진은 내 것으로 채운다

## 기능 현황

유저 스토리 **103개**를 API 오퍼레이션 **104개**로 옮겨 놓았다.

| 도메인 | 기능 | 구현 |
|---|---|---|
| 인증 · 온보딩 · 마이페이지 | 11 | 엔티티 |
| 플래너 | 12 | 엔티티 |
| 지도 · 정원 | 6 | 엔티티 |
| 미디어 | 1 | 엔티티 |
| 타임캡슐 | 7 | 엔티티 |
| 아카이브 | 18 | 엔티티 |
| 커뮤니티 | 20 | 엔티티 |
| 알림 | 6 | 엔티티 |
| 관리자 | 15 | 엔티티 |
| 공통 오류 처리 | 7 | **완료** |

**된 것** — 문서 5종 · DB 스키마(테이블 25개) · JPA 엔티티 25개 · 전역 예외 처리 · 통합 테스트
**다음** — 보안 설정(JWT) · 리포지토리 · 도메인별 API

> 지금은 **모든 경로가 `401`**이다. Spring Security 설정을 아직 쓰지 않아 기본값이 걸려 있다.

## 기술 스택

| | |
|---|---|
| Spring Boot 4.1.1 · Java 21 · Gradle | |
| PostgreSQL 16 | 스키마는 Flyway가 관리한다 |
| Redis 7 | 리프레시 토큰, 콘텐츠랩 응답 캐시 |
| S3 | 사진·영상. presigned URL로 앱이 직접 올린다 |
| WebSocket (STOMP) | 아카이브 실시간 공동 편집 |
| 한국관광 콘텐츠랩 API | 관광지·지역 데이터 |

소셜 로그인은 **앱 SDK 방식**이다. 앱이 받은 토큰을 서버가 제공자 API로 검증하고 자체 JWT를 발급한다.

## 실행

도커가 떠 있어야 한다.

```bash
docker compose up -d     # PostgreSQL · Redis
./gradlew bootRun        # http://localhost:8080
```

환경변수를 따로 넣지 않아도 된다. 처음 뜰 때 Flyway가 스키마를 만든다.

```bash
docker compose down      # 끄기
docker compose down -v   # 데이터까지 지우고 끄기
```

로컬 값을 바꾸려면 `src/main/resources/application.properties`에 넣는다.
이 파일은 `.gitignore`에 있어 커밋되지 않는다.

```properties
DB_URL=jdbc:postgresql://localhost:5432/evergarden
GOOGLE_CLIENT_ID=...
```

### 테스트

```bash
./gradlew test
```

Testcontainers가 PostgreSQL·Redis를 띄운다. 통합 테스트는 컨텍스트를 올리면서
**Flyway 실행 · 엔티티 25개와 스키마 대조 · Redis 연결**을 한 번에 확인한다.

## 문서

설계 근거는 `docs/`에 있다. **명세와 구현이 다르면 구현을 고친다.**

| 문서 | 내용 |
|---|---|
| `docs/user-stories.tsv` | 유저 스토리 103개 — 무엇을 만드는가 |
| `docs/erd.md` | 테이블 25개 — 데이터가 어떻게 생겼는가 |
| `docs/error-codes.md` | 오류 코드 55개 — 실패하면 뭐라고 답하는가 |
| `docs/decisions.md` | ADR 54건 — **왜 그렇게 정했는가** |
| `docs/realtime-editing.md` | 공동 편집 WebSocket 규격 (OpenAPI 밖) |
| `src/main/resources/static/evergardenapi.yaml` | **API 정본** — 오퍼레이션 104개 |

모든 오퍼레이션에 근거가 된 스토리 ID가 `x-user-stories`로 붙어 있다.
**근거 스토리가 없는 엔드포인트는 만들지 않는다.**

`ErrorCode` enum이 `docs/error-codes.md`와 어긋나면 테스트가 깨진다.

## 배포에 필요한 환경변수

개발 프로필은 기본값이 있지만 **운영 프로필은 없다.** 빠뜨리면 기동에 실패한다 —
설정을 놓쳤을 때 조용히 로컬 DB를 보는 것보다 즉시 죽는 편이 낫다.

```
DB_URL  DB_USERNAME  DB_PASSWORD
REDIS_HOST  REDIS_PORT  REDIS_PASSWORD
JWT_SECRET_KEY
GOOGLE_CLIENT_ID  KAKAO_APP_ID
S3_BUCKET  AWS_REGION
```
